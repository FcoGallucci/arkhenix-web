# arkhenix.com

Sitio web de Arkhenix, empresa matriz de Corte Atlas, Cerven, Verbato y el HIS (en desarrollo).

Es un sitio estático: no necesita compilación.

- `public/`: lo que se publica (página, logos, iconos).

## Publicación

Cloudflare Pages está conectado a este repositorio. Cada cambio que se sube a la rama `main` se publica solo en https://arkhenix.com en uno o dos minutos.

Configuración en Cloudflare Pages:

- Framework preset: **None**
- Build command: *(vacío)*
- Build output directory: `public`
